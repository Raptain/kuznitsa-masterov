\# 🏭 КУЗНИЦА МАСТЕРОВ - Генератор подземелий



Веб-приложение для генерации случайных подземелий с визуализацией карты в стиле архитектурной схемы.



\## ✨ Особенности



\- 🗺️ \*\*Генерация подземелий\*\* - случайное создание комнат и связей между ними

\- 📊 \*\*Чёрно-белая карта\*\* - квадратные комнаты, туннели из параллельных линий

\- 🔤 \*\*Буквенные обозначения\*\* - каждый переход имеет латинскую букву (A, B, C...)

\- 📋 \*\*Легенды\*\* - слева типы комнат (с цифрами), справа типы проходов

\- 📄 \*\*Экспорт в DOCX\*\* - скачивание отчёта с картой и описаниями

\- 📊 \*\*Статистика\*\* - отображение количества комнат, связей, сложности

🎮 Использование
Выберите размер подземелья (маленькое/среднее/большое)

Выберите тип (стандартное/пещеры/руины)

Нажмите "СОЗДАТЬ ПОДЗЕМЕЛЬЕ"

Просмотрите карту, таблицу комнат и список связей

Скачайте отчёт в формате DOCX
